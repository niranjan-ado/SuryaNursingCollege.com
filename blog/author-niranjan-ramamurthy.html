Niranjan Ramamurthy

Web developer and Matterport photographer.

Niranjan Ramamurthy is a web developer and professional Matterport photographer. He designed, built and maintains this website for Surya Nursing Educational College. Through Adostrophe, he builds fast, accessible websites and immersive virtual spaces for educational and healthcare institutions.

How this site is built

Many of the college’s visitors are students on phones and mobile data, so the site is hand-written in plain HTML, CSS and JavaScript, with no framework, page builder or build step. Pages work before any script loads: the menus, question lists and syllabus sections all have plain-HTML fallbacks.

  • CSS is organised in cascade layers, with a small set of design tokens. Day and night themes come from one set of colours using the CSS light-dark() function, following the phone’s setting unless the visitor chooses otherwise.
  • JavaScript is split into small native ES modules. Features used on only one kind of page, such as the syllabus tabs or the photo viewer, load only on those pages.
  • Fonts and icons are self-hosted: subset Anek and Mukta typefaces from the Indian foundry Ek Type, and a single SVG icon sprite, so nothing loads from third-party font servers.
  • Images are served as WebP in two sizes, and the phone picks the one it needs. The home page’s drone video is only played when the connection and the visitor’s motion settings allow it.
  • Security: a strict Content Security Policy allows no inline scripts or styles.

Hosting

The site is hosted on Microsoft Azure Static Web Apps, with clean, extensionless URLs and caching rules set in staticwebapp.config.json. Every change goes through a GitHub pull request, which creates a private preview for review before it goes live.

Search

Each page carries structured data (JSON-LD) describing the college, its courses, its questions and answers, and its articles, so search engines can show accurate details to students looking for nursing courses in Jharkhand.
